# Article Annotator

Highlight text and add annotations like Microsoft Word comments.

像 Microsoft Word 批注一样划词高亮、写批注，并在侧栏和批注中心统一管理。

## Features

- **划词高亮与批注**：在 Markdown 阅读/编辑模式选中文字即可高亮或添加批注，支持 PDF
- **批注侧栏**：当前文档的全部高亮与批注，支持搜索、筛选（类型/颜色/标签/时间）、排序、分组
- **批注中心**：跨文件管理所有批注，按文件夹/标签/颜色/时间导航，支持详情预览与原文上下文
- **批注编辑面板**：浮动编辑，Tab 切换颜色，标签管理，贴光标定位
- **导出**：单文件或全库批注导出为 Markdown
- **多语言**：中文 / English

## Installation

### From GitHub Release

1. Download `main.js`, `manifest.json` and `styles.css` from the [latest release](https://github.com/github-oysl/obsidian-annotation-plugin/releases/latest)
2. Copy them into `<your-vault>/.obsidian/plugins/article-annotator/`
3. Enable the plugin in Obsidian settings

### From Obsidian Community Plugins

Search "Article Annotator" in Obsidian's community plugin browser.
