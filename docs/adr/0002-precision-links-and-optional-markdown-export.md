# 首期互链以精确回原文为目标，Markdown 导出按需生成

用户确认首期“互链”的重点是点击批注或复制的链接后打开原始文件的指定位置，并不要求批注自动参与原生图谱。保留插件批注作为编辑来源，提供精确链接与可读 Markdown 导出；不自动生成每书笔记，也不将导出 Markdown 的修改双向同步回批注。

这种选择避免让用户同时维护 JSON 批注和 Markdown 笔记两份可写内容。导出的普通笔记可以自然使用 Obsidian 双链；如以后需要自动伴随笔记，应独立决定内容归属、同步规则和删除行为。
