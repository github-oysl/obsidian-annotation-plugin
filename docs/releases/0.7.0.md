# Scholiast 0.7.0

- 单句段落输入一次标签直接选中，松键保留范围，支持 Enter 编辑及方向键调整。
- 统一电子书侧栏与抽屉，按文档记住面板、字号和阅读布局，改善夜间正文显示。
- 想法输入支持 Tab / Shift+Tab 换色并保持光标，F6 切换控件导航；精确重复范围编辑已有批注。
- 电子书键盘删除支持明确选择及可见页字母标签，失败保留目标供重试。
- 批注撤销覆盖新建、删除、想法、颜色、标签及分组；按文档隔离，批量操作整体恢复。
- 批注中心支持筛选结果批量改色、添加标签和导出；每次导出新快照，包含精确回原文链接。
- 书内搜索支持键盘选结果、退出清理及返回搜索前位置；修复独立窗口初始化和批注交互。
- 作者及许可证署名统一为 slouyang。

最低 Obsidian 版本为 1.13.0。升级时使用同一版本的 main.js、manifest.json 和 styles.css。

已验证单元测试、生产构建、ESLint 和 Chromium 电子书流程；宿主与边界记录见 [操作便利性决策](../design/reading-ux-decisions.md)。Windows、移动设备、原生中文输入法及完整多格式转换套件仍需进一步验收。
