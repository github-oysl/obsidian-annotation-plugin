# 电子书全键盘圈选设计

日期：2026-10-09；实现更新：2026-10-10。状态：已实现并完成浏览器及 macOS Obsidian 隔离宿主验证。真实中文输入法、Windows 与多窗口仍待人工验收。最终选项见 [用户确认决策](keyboard-implementation-decisions.md)，验证证据见 [验证与审核](keyboard-validation.md)。

相关文档：[多格式阅读实现与验证](implementation-status.md)、[多格式阅读与批注设计](reading-and-annotation.md)。

## 1. 已确认目标

正常阅读按页进行，完全使用键盘。需要划线时直接定位目标，支持整段、单句、连续多句及同一章节内跨页范围。只有按住激活键时才进入定位操作，避免普通阅读、输入和快捷键误触。

不把逐句前进作为主要阅读方式。主流程为：正常翻页阅读 → 按住激活键 → 分层定位范围 → 明确确认 → 继续阅读。

## 2. 建议键位与启用条件

功能默认关闭，用户自行启用。以下初始键位允许配置：Space、Backquote、F8；按住时长 120–800 毫秒，初始值 180 毫秒。

| 按键 | 行为 |
| --- | --- |
| 左右方向键 | 无起点时翻页；有起点时逐句移动终点，支持收缩、反向扩展与跨页跟随 |
| 按住 Space 180 毫秒 | 启用当前页的定位标签 |
| 字母标签 | 仅激活键持续按住时，选择段落、句组或句子 |
| Enter | 有起点时打开当前范围编辑器，松键后也可使用；整段预览时需仍按住激活键 |
| Shift+Enter | 兼容打开同一想法编辑器 |
| Backspace | 激活状态下退回上一选择步骤 |
| Esc | 取消全部临时范围及标签 |

只在当前活动电子书正文获得焦点且内容就绪时启用。搜索框、想法输入框、其他可编辑控件、输入法正在组词、其他 Obsidian 面板均不启用。

功能启用时短按激活键不进入定位、不生成批注，并抑制该键的默认滚动，避免激活阈值前页面移动；关闭功能时不处理激活键。以现有左右方向键作为确定的翻页入口。不要采用会在输入标签时触发系统或宿主组合键的默认激活组合。

激活期间标签按物理字母键识别，目标是在中文输入法下无需切换输入法；须验证 Windows/macOS 的组合输入事件，不能假定拦截 keydown 就足够。

## 3. 分层标签与密集内容

第一层只在当前可见页的段落边缘显示标签，如 A、S、D。选择段落后，显示该段可见句子的标签。标题整体作为一个单位；整段只有一句时直接选中该句，省略句子标签层。按整段分句数量判断，不能将多句段落当前页只显示一句的情况视为单句段落。

单段超过 16 个可见句子时，增加句组层，每组最多 8 句，如“第 1–8 句”“第 9–16 句”。选择句组后才显示句子标签，避免短句标签铺满页面。

同一层候选超过单字母容量时采用等长双字母标签，避免 A 与 AA 这类前缀冲突。标签输入支持 Backspace 修正；无效标签不改变范围。标签放在边缘或句首空隙，避免遮挡正文；重叠、双栏、竖排需原型验证。

一次稳定页面上的标签保持不变。翻页、缩放或重新排版后重新生成标签，并丢弃旧页面未完成的标签输入；已选起点/终点使用文档定位信息保存。

## 4. 范围选择流程

### 整段

按住 Space → 选择段落 A → 预览整段 → Enter 打开编辑器，再明确保存。预览期间也可以继续选择句子，将范围缩小到单句。

### 单句

按住 Space → 选择段落 A → 选择句子 D → 预览该句 → Enter 打开编辑器，再明确保存。

整段只有一句时：按住 Space → 选择段落 A → 直接选中该句。松键保留范围，可按 Enter 编辑或用左右键逐句调整；选择终点时也省略重复句子标签。

选择第一个句子后进入“起点已选”状态，显示当前句预览，同时回到段落标签，供用户直接指定另一处终点。

### 连续多句

按住 Space → 起点 A→D → 终点 C→F → 预览连续范围 → Enter 打开编辑器，再明确保存。

首尾两句全部包含，中间文字全部包含，保存为一条批注。端点反向选择时按文档顺序归一化。选择终点段落后可用 Enter 将该段末尾作为终点并确认，或继续选该段具体句子。

首个段落预览尚未选句时松键，取消该临时段落选择；首个句子已选后松键则保留起点。选好范围后需要单独写想法时，使用激活键 + Shift+Enter，沿用现有保存/取消语义。

### 同章节跨页

选好起点 → 松开 Space → 左右键逐句移动终点（跨页自动跟随）→ Enter 打开编辑器，再明确保存。也可以用工具栏翻页，再按住激活键按标签选择终点。

松键后标签消失，保留淡色范围预览及底部“已选起点，待选择终点”提示。无需长时间按住激活键。重新激活时恢复选择终点阶段，绝不把新页标签误当作重设起点。

跨页句子仍按完整句子或段落选择；预览明确显示摘录首尾与跨页提示，避免用户误以为只选了当前页可见部分。

首版限定同一章节中的连续范围。跨章节和不连续选区后续单独设计；不自动拆分为多条批注。若用户翻至其他章节，保留起点并提示返回原章节或取消，不允许误保存跨章节范围。

## 5. 松键、防误触与恢复

| 情况 | 结果 |
| --- | --- |
| 未选起点就松开激活键 | 隐藏标签，取消未完成的标签/段落选择 |
| 已选起点或终点后松键 | 隐藏标签，保留临时范围，退出字母键拦截 |
| 选好起点松键后单独按 Enter | 打开想法编辑器；打开本身不写入批注 |
| 再按住激活键 | 恢复相应选择步骤 |
| 激活中 Backspace | 先退未完成标签/当前层，再撤终点，再撤起点 |
| Esc | 清除整个临时操作，必须松开激活键才能重新激活 |
| 文档切换、窗口失焦、正文失去焦点或视图关闭 | 清除临时范围、计时器和按键状态 |
| 字号或窗口改变导致重排 | 从定位信息恢复范围；内容无法验证时取消确认资格并提示重新选择 |
| 保存中 | 禁止重复提交，显示保存状态 |
| 保存失败 | 保留范围并提示，可重新激活后重试 |
| 保存成功 | 清除临时范围；停在当前阅读页；松键后才允许下一次激活 |

忽略激活键、标签键、Enter 的自动重复事件。必须同时满足激活门槛、有效非空范围、明确的确认按键和当前会话一致，才允许创建批注。松键、翻页、标签命中均不得隐式保存。

## 6. 视觉反馈与编辑返回

临时范围采用淡边框或低饱和预览，与已保存的彩色高亮区分，不写入批注数据。底部提示只在临时操作存在时显示，例如“已选起点：阅读是一种……；选择终点，或按住空格 + Enter 打开编辑器，再明确保存本句”。

预览显示摘录首尾、范围类型和是否跨页。范围全部可见时不强制滚动或自动翻回起点。写想法后恢复正文焦点及阅读位置；取消编辑应可恢复该临时范围，让用户继续调整。

重复范围进入已有批注的编辑器，更新原记录，不创建重复记录。保存后提供键盘撤销最近一次创建的入口；提供统一「撤销（Markdown / 电子书）」命令，由用户自行绑定同一套键位；不设默认快捷键，不专门拦截 Ctrl/Cmd+Z。电子书创建历史仅在本次插件运行中保留。

## 7. 现有实现与技术接入点

当前 Markdown 智能选段在 `src/annotation-range.ts` 的 `resolveAnnotationTextRange()`。它接受源码行与编辑器光标，不能直接用于电子书 DOM。

电子书现有路径：`runtime/ebook-frame.js` 在章节 load 时绑定正文选区与左右翻页，将 DOM Range 通过 `view.getCFI(index, range)` 发送到宿主；`src/reader.ts` 接收范围并创建电子书批注。本轮已通过 `runtime/ebook-keyboard.js` 接入临时圈选状态。

固定引擎版本为 `78914aef4466eb960965702401634c2cb348e9b1+scholiast.1`。`vendor/foliate-js/text-walker.js` 提供文字节点与 DOM Range 映射；`tts.js` 提供按块遍历和 Intl.Segmenter 分段参考。TTS 的 next/prev 以块和朗读状态为主，不能直接当作句子导航。

建议将标签、按键门控、起终点和预览集中在一个正文临时圈选模块，宿主继续负责持久化和想法编辑。正文重建后恢复的是 CFI 与引文，不保留旧 DOM 节点或视觉页码。预览使用覆盖层，避免修改正文文字节点影响定位。

中文引号、英文缩写、小数、跨节点斜体、ruby、脚注、列表、标题和复杂排版都需要明确的切分与过滤规则。过滤隐藏/重复注音内容，并按需处理当前章节与可见区域，避免为了标签解析整本书。

## 8. 先做的原型与验收

1. 在 Obsidian 正文 iframe 验证按住启用、松键暂停、焦点丢失清理、输入法和现有翻页键；先解决快捷键冲突。
2. 当前页段落/句子标签、单句/整段高亮，以及连续多句起终点选择。
3. 同章节跨页、字号变化后定位恢复，写想法后返回正文。
4. 高密度标签分组、失败重试、重复确认和撤销。

必须覆盖：短按、按住重复、标签输入中松键、确认键长按、松键后 Enter、失焦未收到 keyup、搜索/输入框、输入法组合输入、双栏/竖排、跨页句子、反向端点、视图切换、保存失败及相同范围重复操作。

验收标准：不靠鼠标完成上述流程；定位前仍按页阅读；范围与摘录一致；无隐式保存或重复批注；临时状态不串窗口或文档。浏览器验证不能替代 Obsidian 宿主实测。
