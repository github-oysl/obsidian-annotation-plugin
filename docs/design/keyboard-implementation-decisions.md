# 键盘圈选实现决策与验收

日期：2026-10-09；交付更新：2026-10-10。基线：`4e861e1`。依据：`ebook-keyboard-annotation.md`。

## 已确认

- 完整实现键盘圈选，编码与测试完成后再审核验证。
- 本期不增加格式转换，不依赖 calibre。
- 总开关默认关闭，由用户自行启用；激活键与按住时长可配置。
- 默认候选为 Space / 180 毫秒；输入法和宿主冲突必须实测。
- 尽量使用同一套前缀键；撤销键位应与原有 Markdown 行为统一，由用户按习惯绑定。

- 只提供可绑定的统一撤销命令；不拦截 Ctrl/Cmd+Z。Markdown 路由现有编辑器撤销，电子书路由当前文档最近创建批注。
- 默认不绑定额外组合；用户在 Obsidian 快捷键中配置习惯的统一键位。

## 实施顺序

1. 临时状态与键盘门控；正文焦点、短按、重复、组词与失焦清理。
2. 可见段落/句组/句子标签；完整文字范围、反向端点和预览。
3. 同章节跨页、重排恢复与范围核对。
4. 带请求和会话校验的保存、编辑、失败重试、去重与撤销。
5. 行为测试、真实 Chromium、构建、规范与需求审核、可用宿主验证。

临时圈选不写入存储；仅明确确认可保存。浏览器结果和宿主结果分别记录。

## 实际验收反馈后的调整（2026-10-10）

- 用户要求参考原有界面优化阅读器，修复夜间不可读；采用紧凑图标、圆形色板、折叠显示设置/搜索、窄窗口上下布局。
- 选好起点后，左右方向键按完整句子扩展/收缩，松开 Space 后仍有效，跨页跟随终点。没有起点时仍正常翻页。
- Enter 打开编辑器，再明确保存；已有范围进入原记录编辑，保留身份和标签，不重复创建。该决定覆盖初始“Enter 直接高亮”和“松键后 Enter 不处理”的操作设计。
- 主题进入章节文档，字号修改不覆盖主题；统一 HTML 正文颜色，同时保留 CSS URL 背景插图、SVG 配色及固定布局原色。
- 单句段落直接确定起点或终点，省略重复的句子标签选择；松键保留范围，Enter 编辑、方向键调整。按完整段落的分句数量判断，分页只露出一句的多句段落仍进入细选。

## 操作便利性讨论后的范围调整（2026-10-10，已实施）

用户确认将批注撤销扩展到新建、删除、想法、颜色、标签和分组，按原始文档隔离，历史保留本次插件运行期间。此产品范围覆盖前述“电子书只撤销最近创建”的限定，已通过共享批注操作历史实施。具体路由、批量操作、恢复冲突规则及验收结果见 [操作便利性决策](reading-ux-decisions.md)。
