# 多格式阅读实现与验证

日期：2026-10-10。实现依据：[已确认设计](reading-and-annotation.md)。

## 全键盘电子书圈选本轮交付

[圈选设计](ebook-keyboard-annotation.md) 已实现；[用户确认决策](keyboard-implementation-decisions.md) 和 [本轮验证与审核](keyboard-validation.md) 记录具体行为及边界。

- 总开关默认关闭。用户自行启用；激活键可选择 Space、Backquote、F8，按住时长可调 120–800 毫秒，初始值为 Space / 180 毫秒。
- 按住后显示段落、句组、句子标签，支持整段、完整单句、反向端点、连续多句、同章节跨页；选起点后左右键逐句调整范围（松键后仍可使用），Enter 打开想法编辑器，明确保存后才写入批注。松键不保存，Esc 取消，失焦清理，重排用 CFI 与引文恢复。
- 阅读器使用紧凑图标、圆形色板、折叠显示设置与搜索，窄窗口的批注面板置于正文下方；主题与字号同步到章节，保留 CSS URL 插图、SVG 原色和固定布局页面。
- 保存等待持久化结果，失败保留范围，重复范围进入已有批注编辑而不新建；想法取消可继续调整，保存或取消后自动返回正文。
- 提供可自定义绑定的统一「撤销（Markdown / 电子书）」命令：Markdown 使用编辑器历史，电子书撤销当前文档在本次插件运行中最近创建的批注。没有默认快捷键，不专门拦截 Ctrl/Cmd+Z。
- 本期不增加格式转换，不需要 calibre。键盘和宿主样本由测试代码直接生成原创 EPUB。

开发分支为 `codex/ebook-reading-keyboard-handoff`，本轮基线为 `4e861e1`。发布版本为 0.6.0，完整中英文使用手册与开发说明随版本分发。开发构建已按用户要求安装到本地知识库；本轮更新只覆盖插件运行文件，不覆盖设置、笔记或批注数据。此前交接的 16 项测试已扩充为 24 项，24 组 Chrome 圈选验证与 14 组 macOS Obsidian 隔离宿主验证通过。Windows 与真实中文输入法仍待人工验收。

## 已实现

- EPUB/MOBI/AZW3/FB2 原文件阅读视图与逐扩展名注册，冲突时保留命令和文件菜单入口。
- 外部文件复制导入、基本签名/大小检查、同名不覆盖、同名相同内容直接打开、批量逐项显示结果。
- 翻页、目录、书内搜索、字号与分页/滚动布局；选文高亮、想法、标签复用现有卡片和编辑器。
- 按文档保存电子书 CFI/章节、阅读进度和面板开关；同文档视图刷新，切换会话隔离。
- schema v2 文档身份，旧 MD/PDF ID 和内容保留，未知记录与附加字段保留，未来 schema 阻止回写。
- 串行写入、迁移前备份、暂存校验、写后校验、失败恢复；部分宿主适配器不保证原子替换，因此不宣称跨设备事务。
- 文档/父目录改名后保留 ID；删除只标记缺失；二进制摘要与换版引文核对。
- 插件协议精确链接与 Markdown 快照导出；按行、页、章显示位置。
- PDF 文本节点选区修复、目标页就绪等待、页面/区域批注、懒加载和布局重绘；旧归一化矩形保留并标明坐标系。旋转不匹配时保留批注并停止错误重绘。
- 引擎与解压库全部离线内嵌，章节预先清理并施加 CSP，关闭时释放 blob URL；单文件 100 MiB，ZIP 单资源 64 MiB、展开合计 256 MiB 上限。

## 已执行验证

- `npm test`：24 项行为测试通过，覆盖旧数据迁移、未知记录、未来 schema、格式分发、扫描 PDF 页面记录、串行写入、备份与磁盘失败恢复，以及既有编辑交互。
- `npm run build`：TypeScript 与生产打包通过。
- `npm run lint`：Obsidian 规范检查通过，无警告。
- 此前 `npm run test:ebooks`：在 Windows 的真实 Chrome/Chromium 中，以 calibre 从同一原创样本生成 EPUB/MOBI/AZW3/FB2；逐格式验证打开、选文、CFI 高亮、重建阅读器后恢复、调整字号/宽度后精确跳转。
- 恶意 EPUB 样本含 script、事件属性、远程图片、iframe、object、表单和 CSS 外部资源；书内脚本未执行，外部资源由 CSP 拦截，正常选文和恢复仍通过。

- 本轮 `npm run test:keyboard`：24 组真实 Chrome 验证通过，含跨页、重排、双栏、竖排、合成输入法事件门控与保存失败恢复。
- 本轮 `npm run test:host`：macOS Obsidian 1.14.4 独立临时配置及知识库中的 14 组验证通过，含真实 JSON 保存、去重、用户绑定的组合键与 F9 统一撤销、想法取消/保存自动回正文、长章节创建批注后立即关闭重开、第二章与进程重启进度恢复、中英卡片分区、深浅主题及 Markdown 原有撤销历史。

本轮未重跑依赖 calibre 的历史四格式测试；没有以本轮 EPUB 圈选验收替代四格式验收。

浏览器测试使用本地 HTTP 页面与 iframe，属于阅读引擎集成验证，**没有替代 Obsidian 宿主实测**。calibre 只用于生成测试样本，插件运行不依赖 calibre。重新跑此测试需要 Chrome 和 PATH 中的 `ebook-convert`（或 `SCHOLIAST_CALIBRE` 指定可执行文件）。

## 尚需宿主验收

- Windows Obsidian：实际文件列表后缀显示、扩展名冲突/插件禁用、原生 PDF 的长文档/缩放/旋转/页状态、多窗口和重启。
- macOS Obsidian：本轮已有隔离宿主 EPUB 键盘闭环实测；批量外部文件导入、其他三种电子书格式、原生 PDF和多窗口仍待验收；独立宿主的 EPUB 进程重启与进度恢复已通过。
- 真实大书和复杂排版、加密/DRM 文件报错与内存峰值。现有样本不能证明所有出版社文件都兼容。
- PDF 原生文本项 selection 和 PDF 用户空间坐标尚未接入；现有实现使用明确标记的 DOM 归一化区域，并在旋转改变时降级。
- 缺失来源可通过“重新关联缺失文档”关联相同格式的文件；换版失联批注可在 MD/PDF/电子书正文选文后使用“重新指定”。自动列出多个候选的专门界面尚未实现，当前不会自动选择含糊匹配。

本次完成源码与生产构建，已按用户要求安装到本地知识库；0.6.0 按纯版本号 tag 发布；安装只复制插件运行文件，未由安装脚本迁移知识库批注。安装新构建后的首次写入才会产生 v2 和迁移备份，回滚旧插件应使用 `annotations.json.v1-backup.json`。
