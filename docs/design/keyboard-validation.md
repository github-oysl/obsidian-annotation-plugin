## 阅读进度、批注分区与文档反馈

真实 macOS Obsidian 的长章节回归复现：翻五页后聚焦正文，CFI 从后续段落回到首段；保存批注后关闭重开仍在首屏。原因是 `body.focus()` 触发分页器的 `focusin` 导航，进度存储正确写入了错误的当前位置。改为只聚焦章节窗口，避免整章正文成为导航目标。长章节后续页圈选、保存想法、立即关闭后重开，原批注文字仍在当前页；第二章正常重开及独立进程重启后磁盘恢复也通过。允许重排改变页边界，不能以可变页末 CFI 完全相等代替原文位置检查。

切章往返的新增 Chrome 回归复现正文主题丢失：主题变量仍在，但清理出版社配色时删除了插件自己注入的 HTML/body 颜色规则。为自有主题样式加标识并在清理时跳过它后，章节往返与重新打开后的深浅主题通过；插图、SVG 与固定布局保护仍保留。

共享卡片增加“原文摘录 / Source excerpt”“我的想法 / My note”标签、引用块与底色，电子书面板、文档侧栏和批注中心使用同一结构。根 `README.md` 是中英双语图文使用指南，`docs/README.md` 解释源码、数据流、构建和测试；截图从隔离宿主原创样本生成。两项独立审核通过；Spec 指出的跨章节说明及 Standards 指出的陈旧重启/数量记录均已修正。
